# Liquid Glass: локальная итерация 5 ноября 2026

Без push, merge или деплоя. Позиции и траектории орбит сохранены.

- Спутники показывают монохромные логотипы. При выборе переворачиваются на исходный скринкаст; текст видео не локализуется.
- Подпись ядра вынесена под экран без плашки. Названия соседей приглушаются при пересечении с подписью.
- Автосмена через 8 секунд видимого времени, приоритет у мыши и клавиатуры. На мобильном сцена по-прежнему скрыта; при reduced motion автосмены нет.
- Общая тонкая кромка для панелей, скругление секции услуг. Основа больших карточек кейсов непрозрачная, чтобы задние карточки не просвечивали под текстом.
- Размытие не анимируется; видео играет только у активного ядра, вне видимости/в скрытой вкладке приостанавливается.

## Логотипы

- Созидание: оригинальный SVG шапки https://bf-sozidanie.ru/ (включая фирменный росток).
- Camay: https://camay.mw.team/assets/Camay_logo-oWjWX3XV.png, исходный знак проекта, CSS grayscale.
- Coca-Cola: SVG опубликованного https://cola-dc.mw.team/.
- Халва: SVG опубликованного https://halva.mw.team/, кадрирование до знака Халва без Совкомбанка.
- Росатом и Ростелеком: существующие файлы public/brands.
- Английские Halva / Rostelecom / Sozidanie / Rosatom являются локальными типографическими адаптациями, не заявлены официальными английскими логотипами. У Sozidanie и Rosatom сохранены исходные фирменные символы. Coca-Cola и Camay одинаковы в RU/EN.

## Проверка

Сборка, ESLint, TypeScript; браузер 1440×920 и 390×844, RU/EN, светлая/темная тема, переход в галерею, выбор клавиатурой, отсутствие горизонтального переполнения. Физический Safari/iPhone в этой сессии не проверялся.
