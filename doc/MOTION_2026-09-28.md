# Flame Dev · возвращение интерактива

## Направление

Сайт продает разработку через реальные проекты и возможность попробовать отдельные механики

Выразительный визуал, серая база и синее пламя остаются частью характера Flame Dev

Предыдущая статичная итерация слишком сильно убрала этот характер

## Что изменено

- Добавлено поле синих световых линий, форма которого меняется при прокрутке
- Фон останавливается, когда прокрутка закончена, не перехватывает указатель и не создает отдельный сценарий навигации
- На телефоне меньше линий и ограничена плотность пикселей
- При системном уменьшении движения фон статичен
- Вернулись появление заголовков и карточек, объем карточки первого экрана, акценты этапов
- Сохранена сетка кейсов с настоящими материалами и читаемыми подписями
- В направления возвращены четыре исходных демо: складской сканер, скретч-карта, путешествие в микромир и обработка документов
- В каждый момент загружается выбранная сцена, 3D не входит в начальную загрузку главной
- Сцены переключаются вручную, доступны мышь, клавиатура и сенсорные действия
- Варианты форм сохранены без переработки, их отдельная доработка остается следующей задачей

## Запуск вне Sites

Обычные `npm ci`, `npm run dev`, `npm run build` и `npm run start` не зависят от Sites

Все демонстрации работают локально без ключей

Без OpenAI бриф использует базовые вопросы и собирает редактируемое резюме в браузере

Отправка без Telegram возвращает явное состояние недоступности, не имитирует реальную доставку

Модель по умолчанию `gpt-4.1-mini`, переопределяется серверной переменной `OPENAI_MODEL`

Выбор сделан для коротких структурированных уточнений и редактирования текста без отдельного этапа рассуждений

Документация модели https://developers.openai.com/api/docs/models/gpt-4.1-mini

Секрет OpenAI хранится только в окружении сервера, в репозитории находится пустой пример

## Комментарий для дальнейшей работы

Интерактивные сцены являются демонстрациями возможностей, а не интерфейсами проектов клиентов и не реальными акциями

Не убирать эти механики при следующем упрощении страницы

Новый видеоконтент кейсов готовим отдельно, текущие постеры и видео не подменяем придуманными материалами

Главный экран должен сохранять баланс между понятным предложением и выразительной сценой
