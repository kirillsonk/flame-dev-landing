# Flame Dev — дизайн макетов в Figma. Спека

Дата: 2026-09-10. Основание: `doc/flame-dev-spec.md` (ТЗ), вайрфрейм
Figma `aeSryItOTNYW6bQM6dx7IX` (страница Wireframe, десктоп `1:2`,
мобайл `21:2`), презентация «MW Team — Projects showcase», репозитории
`FlameAi/frontend` и `FlameAi/landingv2` как источник бренда Flame AI,
конвенции из vault `LLM Dev Setup`.

## 1. Цель и границы

Собрать в существующем Figma-файле макеты сайта-визитки Flame Dev:
десктоп 1440 и мобайл 390, плюс состояния (ховеры, плавающий CTA,
мягкий баннер, мобильное меню). Макет должен читаться как часть семьи
Flame (тёмная база, TTFirsNeue, радиусы, свечение), но с синим акцентом
вместо красного.

Не входит: анимации и реальное видео, EN-версия, финальные тексты,
код сайта.

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Тема | Полностью тёмная, как Flame AI и Flame CGI |
| Акцент | Кобальт `#3B78FF`, ховер `#6394FF`, текст на акценте тёмный |
| Логотип | FLAME из фирменного SVG Flame AI + DEV надстрочным блоком в той же угловатой пластике |
| Подход к сборке | Гибрид: переменные для цвета, типографики, отступов + компоненты для повторяющихся элементов, секции собираются напрямую |
| Ширины макетов | Десктоп 1440, мобайл 390 (под fluid rem-формулу: `font-size: 10/1440*100vw` и `10/390*100vw`) |
| Типографика | Три размера по ТЗ, без промежуточных |

## 3. Токены

Имена переменных совпадают с будущими CSS custom properties в `:root`.

### 3.1 Коллекция `color` (один режим)

| Переменная | Значение | Роль |
|---|---|---|
| `color/bg` | `#262525` | фон страницы |
| `color/surface` | `#2D2C2C` | карточки, панели |
| `color/elevated` | `#3D3D3E` | постеры-заглушки, ховер chrome-кнопки |
| `color/border` | `#3D3D3E` | все бордеры 1px |
| `color/border-strong` | `#9D9C9E` | нижняя линия инпутов |
| `color/text` | `#FCFBFB` | основной текст |
| `color/text-dim` | `#9D9C9E` | вторичный текст, описания |
| `color/text-cold` | `#B4BBC4` | подписи под шагами, мелкие строки |
| `color/action-primary` | `#3B78FF` | кнопка primary, ссылки, активный шаг, заливка таймлайна |
| `color/action-primary-hover` | `#6394FF` | ховер акцента |
| `color/on-action` | `#262525` | текст на акцентной заливке |
| `color/glow` | `#3B78FF` 26% | свечение за hero и вокруг CTA (42% на ховере) |
| `color/success` | `#31D269` | успешная отправка формы |
| `color/error` | `#F70E3D` | ошибка поля |

Нажатое состояние primary-кнопки: заливка `color/text`, текст
`color/action-primary` (инверсия, как в Flame AI).

### 3.2 Коллекция `size` (режимы Desktop 1440 / Mobile 390)

| Переменная | Desktop | Mobile |
|---|---|---|
| `type/display` | 48 | 36 |
| `type/title` | 24 | 24 |
| `type/body` | 16 | 16 |
| `space/section` | 120 | 80 |
| `space/gutter` | 120 (поля контейнера) | 20 |
| `space/grid-gap` | 24 | 16 |
| `size/button` | 48 | 48 |
| `size/button-hero` | 56 | 52 |

Шкала отступов внутри компонентов: 4, 8, 12, 16, 24, 32, 48, 64.
Контейнер 1200 внутри 1440, колонки 12, межколонник 24.

### 3.3 Текстовые стили

| Стиль | Размер | Вес | Трекинг | Интерлиньяж | Примечание |
|---|---|---|---|---|---|
| Display | `type/display` | 700 | −3% | 110% | hero курсивный, заголовки секций прямые |
| Title | `type/title` | 700 | −2% | 115% | названия карточек, шаги |
| Body | `type/body` | 400 | 0 | 150% | описания, теги, кнопки, навигация |

Семейство TTFirsNeue, файлы в `FlameAi/landingv2/public/fonts/TTFirsNeue/`.

### 3.4 Форма

Радиусы: 8 контролы и теги, 14 карточки кейсов и услуг, 16 стеклянные
панели (плавающий CTA, мягкий баннер), 999 чипы. Бордеры 1px. Тени
только ореол CTA: `0 0 44px color/glow, 0 6px 20px rgba(0,0,0,.38)`.
Стекло: `color/surface` 55% + blur 14.

## 4. Компоненты

Примитивы с префиксом `Base/`, блоки страницы по секциям. Слои внутри
именуются плоским BEM (`hero__title`, `caseCard__poster`), чтобы имя
слоя совпадало с классом в SCSS.

| Компонент | Варианты | Спека |
|---|---|---|
| `Base/Button` | primary, inverse, chrome, ghost × M 48 / L 56 × default, hover | padding 0 24, радиус 8, Body 500; primary с ореолом; inverse = заливка `color/text`, текст `color/action-primary`, только на синей CTA-полосе |
| `Base/Tag` | outline, accent | высота 32, padding 0 12, радиус 8, Body |
| `Base/Input` | default, focus, error | без рамки, нижняя линия 1px `color/border-strong`, фокус акцентом, высота 48 |
| `Base/Textarea` | те же | высота 120 |
| `Base/NavLink` | default, hover | Body, ховер `color/text-dim` → `color/text` |
| `Logo/FlameDev` | header, footer | FLAME из SVG + DEV блоком; высоты 22 / 18 |
| `Hero/Strip` | collapsed 187×620, expanded 420×620 | постер кейса, подпись Title снизу слева, скрим |
| `Card/Case` | L 588×498, M 384×378, S 282×298 × default, hover | постер в цветах бренда, Title, Body dim, теги; ховер: бордер акцент 55%, лёгкий подъём |
| `Card/Service` | 4 контентных варианта | 588×383, слот визуала 532×220 с подписью «интерактив», Title, Body, 3–4 тега стека |
| `Card/Why` | default, featured | 384×212; featured (Flame AI) с бордером акцентом |
| `Process/Step` | default, active | номер Display, Title, Body cold; active подсвечивает номер акцентом |
| `Card/Ecosystem` | Flame CGI, Flame AI | 588×144, Title, Body, ссылка |
| `Cta/Floating` | button, expanded | стекло 16, мини-форма имя + контакт + кнопка |
| `Cta/MobileBar` | одно состояние | полоса 390×64 с primary-кнопкой во всю ширину |
| `Banner/Soft` | одно состояние | стекло, текст + кнопка + крестик, 360 шириной |
| `Header` | desktop, mobile, mobile-open | sticky, логотип, навигация, RU/EN, кнопка |
| `Footer` | desktop, mobile | логотип, ссылки, Flame CGI / Flame AI, соцсети, RU/EN |

## 5. Структура файла

- `Wireframe` — без изменений.
- `01 Foundations` — палитра, типографика, логотип, радиусы, сетка.
- `02 Components` — все компоненты из раздела 4.
- `03 Desktop 1440` — один фрейм страницы по секциям 00–08.
- `04 Mobile 390` — один фрейм страницы.
- `05 States` — ховеры карточек и полос, плавающий CTA в двух состояниях, мягкий баннер, мобильное меню, липкая панель, ошибка формы.

## 6. Десктоп 1440, секции

**00 Header.** Высота 80, sticky. Логотип слева, навигация Кейсы ·
Услуги · Процесс · Контакт, RU/EN, primary-кнопка «Обсудить проект».

**01 Hero.** Заголовок Display курсив «Сложные системы и спецпроекты
для брендов» в две строки, справа три строки Body: `[N] лет`, `[N]
проектов`, «Полный цикл: дизайн · разработка · видео». Ниже пять полос
620 высотой: Coca-Cola × Delivery Club раскрыта, Росатом, Flame AI,
Tibia, Amatour свёрнуты. Позади полос радиальное свечение `color/glow`
с блюром 60. Никаких логотипов клиентов.

**02 Кейсы.** Заголовок Display. Ряд 1: L-карточки Coca-Cola × Delivery
Club и Росатом. Ряд 2: M-карточки Flame AI, Tibia / Majorpack, Amatour.
Ряд 3: S-карточки Purina × VK, AliExpress × ОК, Majorpack, Фонд
«Созидание». Под сеткой строка Body: «Huawei — редизайн главной, дизайн-
проект → Behance». Без метрик.

**02b CTA-полоса.** Заливка `color/action-primary` на всю ширину, высота
160, текст Title `color/on-action` «Есть задача? Расскажите, ответим в
течение дня», справа кнопка в светлой заливке. Единственный сплошной
синий блок на странице.

**03 Что мы делаем.** Заголовок Display, четыре `Card/Service` 2×2.
Слоты визуалов: таблица Tibia, поле мини-игры «три в ряд», 3D-объект
Росатома, промпт Flame AI с кадром. Под каждым визуалом подпись
«интерактив» и уровень анимации (раздел 9).

**04 Один подрядчик вместо трёх.** Три `Card/Why`, третья featured.

**05 Как проходит проект.** Заголовок Display. Таймлайн 8px, залит
акцентом до активного шага, пять `Process/Step` в ряд, второй активный
для демонстрации. Под шагами строка Body cold: «Один менеджер на проект,
демо каждые две недели, без сюрпризов по срокам».

**06 Flame — это ещё и.** Две `Card/Ecosystem`.

**07 Расскажите о задаче.** Слева заголовок Display, Body dim, три
ссылки акцентом (Telegram, почта, PDF). Справа форма: имя, Telegram или
почта, коротко о задаче, primary-кнопка «Отправить».

**08 Footer.** Высота 96, логотип, ссылки, RU/EN.

## 7. Мобайл 390

Один столбец, поля 20. Header 64 с логотипом, RU и бургером. Hero:
Display 36 курсив, три строки Body столбиком, полосы как свайп-карусель
(одна раскрыта 290×460, следующая выглядывает), пять точек, primary-
кнопка во всю ширину. Кейсы столбиком в порядке значимости, все
карточки 350 шириной, постер 16:10. CTA-полоса, услуги и «почему»
столбиком, процесс горизонтальным скроллом с таймлайном, экосистема,
форма, футер. Липкая панель `Cta/MobileBar` показана на отдельном
фрейме в `05 States`.

## 9. Аннотации для разработки

В `03 Desktop 1440` рядом с секциями стоят заметки с уровнем анимации
по конвенции «три уровня эскалации»:

- Уровень 1, IntersectionObserver + CSS-transition: появление секций,
  раскрытие полос hero (flex-transition ширины, авто-ротация таймером),
  ховеры карточек, таблица Tibia, печатающийся промпт Flame AI, мини-
  игра (обычный React-стейт).
- Уровень 2, GSAP ScrollTrigger: pinned-скролл процесса и заливка
  таймлайна.
- Уровень 3, vanilla Three.js в классе: только 3D-объект Росатома.

Прочие пометки: мобильная карусель hero на swiper; форма на Formik +
Yup; hero не привязан к 100vh; постеры грузятся мгновенно, видео лениво
по вьюпорту; плавающий CTA появляется после hero и скрывается на секции
07.

Открытый вопрос для этапа разработки, на макет не влияет: ТЗ говорит
про React/Next.js, конвенция vault для лендингов — Vite + React + SCSS
Modules + `helpers/`.

## 10. Критерии готовности

- Все цвета, размеры и отступы в макете привязаны к переменным, нет
  hardcoded значений в секциях.
- В макете ровно три размера шрифта.
- Каждый повторяющийся элемент — инстанс компонента из `02 Components`.
- Десктоп и мобайл собраны на всех секциях 00–08.
- `05 States` содержит все состояния из раздела 5.
- Слои названы по BEM, секции подписаны номерами из ТЗ.
