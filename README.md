# Flame Dev

Сайт направления разработки внутри экосистемы Flame

## Быстрый запуск

Рекомендуемая версия Node.js указана в `.nvmrc`

```bash
npm ci
npm run dev
```

Локальная проверка релизной сборки

```bash
npm run check
npm run start
```

`check` выполняет сборку, проверку ESLint и TypeScript последовательно

## Основные документы

- `BRAND.md` содержит постоянные правила бренда и текста
- `doc/FLAME_DEV_WEBSITE_COPY.md` содержит рабочий копирайт и редакционные комментарии
- `doc/WORKFLOW.md` описывает работу с GitLab, GitHub и предпросмотром
- `doc/SITE_AUDIT_2026-09-25.md` содержит аудит и план следующей визуальной итерации
- `AGENTS.md` и `CLAUDE.md` задают правила работы агентов

## Переменные окружения

Названия переменных находятся в `.env.example`

Для локальной доставки заявок создать `.env.local` и указать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`

Секреты не добавляются в Git и не передаются в клиентский код

Без настройки Telegram форма сообщает об ошибке отправки, а сервер возвращает 503

## Репозиторий и публикация

GitLab остается основным источником истории и изменений

GitHub при подключении используется как приватная копия той же истории и площадка для совместимой работы инструментов

Публикацию для совместного просмотра планируем через Sites на домене ChatGPT

Локальный предпросмотр работает независимо от хостинга по `doc/WORKFLOW.md`
