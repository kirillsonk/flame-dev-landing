# Flame Dev

Сайт направления разработки внутри экосистемы Flame

## Быстрый запуск

Рекомендуемая версия Node.js указана в `.nvmrc`

```bash
npm ci
npm run dev
```

Для запуска не нужны Sites, аккаунт OpenAI или файл с переменными окружения

Все изображения, шрифты и интерактивные демонстрации входят в репозиторий

Локальная проверка релизной сборки

```bash
npm run check
npm run start
```

`check` выполняет сборку, проверку ESLint и TypeScript последовательно

## Переменные окружения

Названия переменных находятся в `.env.example`

Для локальной доставки заявок создать `.env.local` и указать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`

Секреты не добавляются в Git и не передаются в клиентский код

Без настройки OpenAI используются заранее подготовленные вопросы, резюме брифа собирается локально и доступно для редактирования

Витрина AI в блоке услуг является локальной демонстрацией на примерах и не обращается к API

Без настройки Telegram форма сохраняет введенные данные и сообщает о недоступности отправки, сервер возвращает 503

Заглушки не выдают демонстрацию за ответ GPT и не показывают ложное подтверждение отправки

Для реального AI достаточно `OPENAI_API_KEY`, по умолчанию используется `gpt-4.1-mini`

Необязательная `OPENAI_MODEL` позволяет заменить модель без правки кода

## Репозиторий и публикация

GitHub с remote `github` является основным репозиторием для текущей работы и публикации

Текущие изменения ведутся в `dev`. Ветка `main` автоматически деплоится в production на Timeweb

Merge и push в `main` выполняются только по явному разрешению владельца после проверки результата

GitLab с remote `origin` и предпросмотр на Sites относятся к исторической схеме

Обычный Next.js запускается на любом совместимом Node.js-хостинге через `npm run build` и `npm run start`

`npm run build:sites` является историческим адаптером публикации и не нужен для текущего процесса

Локальный предпросмотр работает независимо от хостинга на `http://localhost:3101/` по `doc/WORKFLOW.md`
